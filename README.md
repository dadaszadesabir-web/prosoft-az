# ProSoft AZ sayt faylları

## Fayllar
- `index.html`: saytın özü. Kompüterdə brauzerdə açaraq önizləyə bilərsən.
- `README.md`: bu təlimat.

## WhatsApp nömrəsini əlavə et
`index.html` faylında `const WHATSAPP_NUMBER = "BURAYA_NOMRE_YAZ";` sətrini tap.
`BURAYA_NOMRE_YAZ` yerinə nömrəni ölkə kodu ilə, yalnız rəqəmlərlə yaz. Azərbaycan üçün nümunə format: `994501234567` (bu nümunə real əlaqə nömrəsi deyil).

## GitHub Pages-də dərc et
1. https://github.com saytına daxil ol və hesab yarat / daxil ol.
2. `New repository` seç, adını `prosoft-az` yaz və `Public` seç.
3. `Add file` → `Upload files` seç, `index.html` faylını yüklə və `Commit changes` et.
4. Repository-də `Settings` → `Pages` bölməsinə gir.
5. `Deploy from a branch` seç, branch olaraq `main`, qovluq olaraq `/(root)` seç və `Save` et.
6. Bir neçə dəqiqədən sonra Pages bölməsində göstərilən sayt linkini aç.

## Vacib
- GitHub Pages statik sayt host edir. Bu forma sifarişi serverdə saxlamır, WhatsApp mesajı hazırlayır.
- Ödəniş qəbul etmək üçün ayrıca etibarlı ödəniş xidməti lazımdır.
- Kataloqda hələ APK yükləmə linkləri yoxdur. Yalnız rəsmi və ya yayılmasına açıq icazə verilən faylları əlavə et.
